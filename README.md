# AMAR.IO

agar.io in full 3D. Fly any direction, split, devour, and grow into a colossal sphere.

**Play:** https://onehundredapps.github.io/amar.io/

- Instant browser multiplayer (peer-to-peer WebRTC, no server), with AI bots so every lobby is alive
- Arrow keys steer · Shift boost · R rocket · Space split · F eject · S brake · H hide HUD
- Power-ups: NITRO boost, STEROIDS (2× growth), ROCKETS that shatter targets
- Grow one ball to max size to fill the cage and win: the world resets
- Works on phones (touch stick + buttons)

Single-file game (`index.html`): Three.js + custom shaders, Trystero for networking.
Built entirely by Claude Opus 5.5 as an experiment.
